# feedback

Public feedback on [Hiker Atlas](https://www.hikeratlas.com): bugs, ideas,
mistakes on the map, and reports of content that shouldn't be there.
[Open an issue](https://github.com/hikeratlas/feedback/issues/new/choose).

## Reporting content

Reviews, tracks, photos and faves on Hiker Atlas are records in people's own
[AT Protocol](https://atproto.com) accounts. Hiker Atlas indexes them so they
can be shown on hike pages; it doesn't store them.

Each one has a "Report" link, which opens a report here. When we act on a
report, we hide the record (or the whole account) from Hiker Atlas. We can't
delete it: it stays in its author's repository, which only they or their
hosting provider can change. Other apps may still show it.

Issues here are **public**. Don't put anyone's personal information in a
report: the link to the record is enough.

## Labels

- `report`: a report of content
- `feedback`: everything else
- `handled`: we've acted on it
